# نتیجهٔ بررسی نسخهٔ JWT

تاریخ بررسی: 2026-10-12

۳۲ تست unittest با موفقیت اجرا شدند. درخواست‌های HTTP با TestClient از مسیرهای واقعی FastAPI و SQLAlchemy عبور کردند؛ دیتابیس SQLite موقت بود.

- CRUD و اعتبارسنجی ورودی، ماندگاری و قیدهای دیتابیس.
- ساخت کاربر با ابزار پروژه، هش Argon2 و ورود با همان کاربر.
- عمر Access و Refresh، ویژگی‌های کوکی و عدم ارسال کوکی Secure روی HTTP در cookie jar تست.
- CSRF نامعتبر، Origin نامعتبر و اتصال CSRF به نشست.
- انقضا، امضای اشتباه، الگوریتم اشتباه، claim ناقص و نوع توکن اشتباه.
- refresh، بازپخش، درخواست هم‌زمان و سقف ثابت عمر نشست.
- logout، پاک‌کردن کوکی و رد توکن کپی‌شدهٔ نشست باطل‌شده.
- جداسازی هزینه‌های دو کاربر و غیرقابل مشاهده بودن رکورد قدیمی بدون مالک.
- migration رفت‌وبرگشت، حفظ دادهٔ قدیمی و تطابق مدل با schema از طریق Alembic check.
- کلاینت نمونه با یک تلاش تمدید و تکرار درخواست، بدون درخواست رمز دوباره.

یک هشدار deprecation از Starlette دربارهٔ پشتیبانی آیندهٔ httpx چاپ شد؛ تست‌ها با نسخهٔ pinشدهٔ فعلی موفق بودند.

این بررسی، آزمون مرورگر واقعی، ممیزی مستقل امنیت، آزمون نفوذ یا تأیید استقرار عمومی نیست. گواهی HTTPS روی سیستم کاربر نصب نشده است؛ دستورهای راه‌اندازی در README آمده‌اند.
